# Mission: Graph Engineering

## Why
Build a GraphRAG project: an LLM application that answers questions by retrieving connected facts from a graph instead of only flat text chunks.

## Success looks like
- Model a small domain as a property graph (nodes, edges, properties) from the questions the app must answer
- Load LLM-extracted entities and relationships into a graph database and query them
- Explain what graph algorithms (e.g. community detection) add to retrieval, and run one
- Ship a working GraphRAG prototype (target: a project, date TBD)

## Constraints
- Prior knowledge: Python and SQL; no graph experience
- Direction is open: graph databases + data modeling first, graph algorithms as the mission needs them (user is unsure how deep to go)

## Out of scope
- Graph neural networks
- Graph theory for its own sake (proofs, interview puzzles)
