From sentences to a graph

Lesson 1 · about 10 minutes · Mission: build a GraphRAG project · Reference card

The win

By the end you can look at a sentence and say which parts become nodes and which become edges. A GraphRAG pipeline does exactly this step, with an LLM, for every chunk of your documents.

The idea

A node is a thing. An edge is a named, directed link between two nodes. The modeling approach taught in Neo4j's data modeling course is to split your data into statements, then use the nouns as nodes and the verbs as relationships (Graph Data Modeling Fundamentals, as described in search results; I could not open the page itself).

From SQL, think of nodes as rows and edges as foreign keys that you can name, point, and follow without writing a join.

The statement "Ada Lovelace worked with Charles Babbage" becomes:

(Ada Lovelace) -[WORKED_WITH]-> (Charles Babbage)

Why this matters for GraphRAG

The Microsoft GraphRAG paper has an LLM extract an entity knowledge graph from the source documents, then group closely related entities and summarise each group (Edge et al., 2024). The first stage is the node-and-edge step you are practising now. The paper's motivation is questions about a whole corpus, which plain chunk retrieval handles poorly.

Retrieval practice

Answer from memory before peeking at the card. Every answer has the same length, so no option gives it away.

In "Ada Lovelace worked with Charles Babbage", what is "Ada Lovelace"?

A person is a thing, so it is a node. Edges name how two things relate.

What is "designed" in "Charles Babbage designed the Analytical Engine"?

It is the verb linking two nodes, so it becomes the edge, pointing from Babbage to the Engine.

Two sentences both mention the Analytical Engine. After merging duplicates, how many nodes represent it?

One shared node is what lets you travel from Babbage through the Engine to anyone else linked to it. Merging mentions of the same thing is called entity resolution; GraphRAG's indexing does it after extraction, according to the docs mirrors I found.
