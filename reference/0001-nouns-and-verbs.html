Nouns become nodes, verbs become edges

Reference card from Lesson 1

  • Node: a thing (person, machine, paper).
  • Edge: a named, directed link between two nodes. The verb gives it a name.
  • Statement to graph: (Charles Babbage) -[DESIGNED]-> (Analytical Engine)
  • Same thing, one node: merge duplicate mentions (entity resolution) so paths can connect.
  • SQL view: node is like a row, edge is like a named foreign key you can follow.
